List of roadmap features, in no particular order:

## Agent integration

Possibly exposing the app as an MCP server for agents to talk to. Expose the most common operations:

- get article list
- get article (a specific one)
- search
(and possibly others)

## "Today" feed

Modelled just like Feedly's today feed.

## OPML import and export

Ability to import OPML files, e.g., from Feedly into the sources quick and easily via the aggregator's admin functionality.

Conversely, provide the ability to export as well.
